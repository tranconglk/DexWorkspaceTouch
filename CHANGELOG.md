# Changelog

## 1.0.0-beta.1

- Touch-first Workspace Designer with templates supporting up to five cells.
- Installed-app picker and multi-window workspace launch on Samsung DeX.
- Local Room persistence with pin, search, sort, and duplicate workflows.
- Workspace import/export using `.dwt`.
- Library backup/restore using `.dwtbundle`.
- Multi-select with batch pin, unpin, export, and delete actions.
- Compatibility testing on Samsung Galaxy S23 Ultra and Note 8 hardware running a Note 9 ROM.

This is a beta build, not a claim of compatibility with untested devices or ROMs.
